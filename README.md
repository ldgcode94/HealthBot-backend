# HealthBot Backend

This is the backend for **HealthBot**, an AI-powered assistant that helps users get reliable general medical information using GPT-4.

## 🧠 Features

- GPT-4 integration for generating safe, general medical responses
- Modular, clean architecture inspired by DDD
- RESTful API

## 🛠️ Tech Stack

- Node.js
- Express
- TypeScript
- OpenAI API

## 🚀 Getting Started

```bash
npm install
npm run dev
```
